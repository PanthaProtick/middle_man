# Landing Page Surface Brief

## Scope and Visitor Mode
- Scope: Root public landing page when seller is not logged in (`/`).
- Visitor Mode: Persuade.

## Audience and Strategy
- Target: Bangladeshi social-commerce (F-commerce) sellers selling via Facebook, WhatsApp, and Instagram.
- Job: Overcome trust hurdles, bogus orders, and manual reconciliation between chat agreement and delivery dispatch.
- Action: Step-by-step interactive workflow walkthrough showing chat -> buyer link -> payment claim -> shop desk reconciliation -> Pathao courier dispatch, concluding with Sign In / Shop Setup.
- Memorable moment: An interactive visual product tour showing a realistic Dhaka chat order turning into a live buyer link with advance breakdown and Pathao delivery slip.

## Direction contract
THESIS: Stop lost deliveries and fake orders before courier dispatch; refuse generic SaaS dashboard hero grids in favor of an authentic Dhaka social commerce workflow tour.
OWN-WORLD: Modern Dhaka Shop Desk in pine teal (#146653), warm eggshell grounds (#f5f6f2), crisp white cards, bilingual EN/বাংলা typography, and tabular monetary amounts.
STORY: Sellers see how simple chat sales turn into secure buyer confirmation links, advance payments get matched without confusion, and Pathao consignments get prepped in seconds.
FIRST VIEWPORT: High-contrast hero with bold Dhaka shop desk value proposition, bilingual toggle, primary "Get Started" sign-in action, and an interactive phone-and-desk preview demonstrating the 3-step confirmation mechanism.
